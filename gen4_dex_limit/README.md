# Gen 4 Pokedex Limit

Companion mod for National Dex.

## What it does

Keeps the National Dex's complete Pokemon registry intact, but limits the Pokemon visible in the Pokedex listing to #001-#493 (Generations 1-4). #494-#1025 remain registered and available to other mods/features.

## Installation

Install the `gen4_dex_limit` folder as a normal Gen1Recomp mod alongside National Dex. National Dex must remain enabled; this companion deliberately loads after it.
